# Hytale AI Companion Mod

Modyfikacja na zajęcia ze Sztucznej Inteligencji w Grach Komputerowych.

## Instrukcja uruchomienia dla zespołu:
1. Pobierz kod z GitHuba: `git clone <link_do_repozytorium>`
2. Wejdź do folderu `app/`. Jeśli nie ma w nim folderu `libs`, stwórz go (`app/libs/`).
3. Zlokalizuj na swoim komputerze oficjalny plik serwerowy Hytale (`HytaleServer.jar`).
4. Skopiuj `HytaleServer.jar` i wklej go do folderu `app/libs/`.
5. Otwórz projekt w IntelliJ IDEA i kliknij ikonkę "Load Gradle Changes" (Odśwież Gradle), aby zaciągnąć bibliotekę.
6. Graj i testuj! (Aby używać AI, wpisz w grze `!ai -setup <TWÓJ_KLUCZ>`).
